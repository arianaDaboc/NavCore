    Odometry calibration

    Currently on the robot: —

    1. Distance. Set the route to 200 cm with no obstacles and start. Mark one point of the robot (for example its rear) on the floor at the start and at the stop, then measure the distance between the marks with a tape.

    Distance the robot believes it drove: — (do a run first)

    2. Rotation. Line up one edge of the robot with a line on the floor (tape or a tile joint) and press the button: the robot turns one full circle to the right on the spot, using the gyroscope.

    Gyroscope measured: — (run the test first)

    If it turned more than one circle, enter 360 + the extra (e.g. 365); if less, 360 − the shortfall (e.g. 354).

    Works only with the robot connected and stopped.

    Firmware over Wi-Fi

    In the Arduino IDE: Sketch → Export Compiled Binary. Then choose the file navcore_wifi.ino.bin from the project's build folder. The password is AP_PASS (or OTA_PASS) from wifi_secrets.h.

    Works only with the robot connected and stopped.
